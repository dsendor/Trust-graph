Start here, if you are new to this

Every ten years or so, American astronomers and particle physicists each write a report that ranks what they want built next: telescopes, particle detectors, accelerators. Governments mostly follow the ranking. Each ranked item is a promise: build this, for roughly this much, by roughly this date, and it will answer a specific scientific question. This page checks those promises against what actually happened.
